The GO SPARQL endpoint has been retired


The public GO RDF/SPARQL services were retired in late 2026, after being marked deprecated since July 2024. This includes:

  • https://rdf.geneontology.org (including https://rdf.geneontology.org/blazegraph/sparql)
  • https://sparql.geneontology.org
  • The query interface previously hosted on this page

No replacement SPARQL endpoint is planned.

Supported alternatives

  • GO API – programmatic access to the ontology, annotations and GO-CAM models
  • GO-CAM downloads – GO-CAM JSON files, plus the gocam-py Python package
  • Ontology and annotation downloads
  • DOI-versioned releases on Zenodo and in the GO Archive

Full details are in the retirement announcement. If you depended on the SPARQL endpoint, please contact the GO Helpdesk and we can advise on alternatives.
